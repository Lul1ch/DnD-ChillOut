# Описание
Специальная расходная единица, которая восстанавливается в начале каждого раунда битвы. Ответное действие можно потратить на выполнение следующих действий вне своего хода:
- Выполнить оружием ближнего боя атаку по врагу, выходящему из [[Зона контроля|зоны контроля]] персонажа. Оружие ближнего боя в это время должно быть в руках;
	- Сюда же входят специальные атаки, которые становятся доступны некоторым персонажам.
- Использование некоторых специальных приёмов, в описании которых требуется ответное действие.
