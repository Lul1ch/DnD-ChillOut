# Описание
**Среднее негативный эффект**
Существо под этим эффектом не может атаковать существо, наложившее этот эффект. В начале хода существо под этим эффектом проходит проверку Воли по сложности 10, при провале выполняет одно простое действие по приказу очаровавшего его субъекта.
