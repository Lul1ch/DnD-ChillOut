# Описание
Удача - особая характеристика персонажа, которая работает не так, как другие характеристики персонажа. Общее значение этой характеристики является показателем удачливости персонажа, игрок может использовать одну единицу удачи для выполнения следующих действий:
- Выполнение повторного броска кубиков при провальной проверке;
- Сделать удачную проверку критической;
- Нейтрализовать помеху при выполнении проверки;
- Заменить модификатор проверяемой характеристики на текущий показатель удачи (модификатор от степени изучения навыка при этом не учитывается).
Каждое такое использование снижает показатель удачи на один, удача полностью восстанавливается после долгого отдыха.
