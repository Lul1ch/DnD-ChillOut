# Описание
**Дистанция** — 12 метров.  
**Цель** — до 3 существ.  
**Уровень ячейки** — 3.

Каждая цель совершает спасбросок Воли. Для каждой провалившей цели бросьте 1d4:

- 1: она падает с ног.
- 2: она немедленно перемещается на 3 метра в случайном направлении по доступному безопасному пути. Это перемещение не провоцирует атак по возможности.
- 3: она не может совершать [[Ответное действие|ответные действия]] и получает помеху на атаки до конца своего следующего хода.
- 4: она немедленно совершает одну обычную атаку по случайному существу в своей досягаемости.

**Использование ячейки более высокого уровня** — количество целей увеличивается на одну за каждый уровень ячейки выше 3-го.
