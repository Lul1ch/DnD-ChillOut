# Описание
Дистанция — 18 метров  
Цели — Сова лесничего  
Тип урона — силовой  
Уровень ячейки — 2
**Длительность** - 3 раунда

На 3 раунда когти Совы покрываются призрачным сиянием. Один раз за каждый свой ход при попадании атакой она наносит дополнительно 1d6 силового урона.

После такой атаки, независимо от попадания, Сова может переместиться на 3 метра без провоцирования атак по возможности. Это перемещение расходует её обычную дальность перемещения.

Использование ячейки более высокого уровня — увеличивает дополнительный урон на 1d6 за каждый уровень ячейки выше 2-го.
