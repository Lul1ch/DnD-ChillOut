# Описание
**Сильное негативное состояние**
Вы получаете штраф в зависимости от уровня истощения:

| Уровень истощения | Эффект                                                                                                                                                                                  |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1                 | Ко всем броскам (атака, урон, спасброски, проверки характеристик и навыков)                                                                                                             |
| 2                 | Ко всем броскам, скорость −3 метра передвижения                                                                                                                                         |
| 3                 | Ко всем броскам, скорость −6 метров передвижения, не может совершать ответное действия                                                                                                  |
| 4 и более         | Ко всем броскам, скорость −9 метров передвижения, каждый ход существо делает проверку Стойкости по сложности 16, при провале получает случайный сильный негативный эффект или состояние |
Как снимается:

| Способ снятие                                               | Количество снимаемых уровней |
| ----------------------------------------------------------- | ---------------------------- |
| Короткий отдых                                              | -1 уровень                   |
| Длинный отдых                                               | -2 уровня                    |
| Магия: заклинания лечения, восстановления, снятия проклятий | В зависимости от эффекта     |
Что вызывает:

- Длительный бой без отдыха
- Критический провал спасброска от яда, болезни, проклятия
- Магические эффекты (некоторые заклинания, ловушки, артефакты)
- Голод, жажда, отсутствие сна
- Смертельные раны, воскрешение
